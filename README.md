# Lei Ge — Personal Website

A single-page academic and creative portfolio for Lei Ge, bringing together
scientific AI, materials research, computational fashion, publications, talks,
experience, and news.

## Content updates

The homepage content lives in `app/page.tsx`. Add new updates to the top of the
`news` array. Visual styling is in `app/globals.css`.

## Local development

```bash
npm run dev
```

## Validation

```bash
npm test
```
